Interface Angular para evolucao de mutation testing com UX focada em clareza para times de qualidade.

## Executar Localmente
```powershell
cd <caminho-do-projeto>
npm.cmd install
npm.cmd start
```

Acesse:
- http://localhost:4200

## Scripts
- `npm run start`
- `npm run build`
- `npm run watch`
- `npm run test`
